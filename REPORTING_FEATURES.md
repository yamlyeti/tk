# 📊 Comprehensive Reporting & Analytics

## 🎉 New Dashboard Features

Your time tracking app now includes a powerful reporting and analytics dashboard with multiple views and insights!

### Report Types

#### 1. 📊 Overview Report
**Summary Cards:**
- **Total Time** - Total hours/minutes tracked
- **Total Entries** - Number of time entries
- **Days Tracked** - Unique days with time entries
- **Avg Per Day** - Average time logged per day
- **Avg Per Entry** - Average duration of each entry
- **Active Projects** - Number of projects with tracked time

**Top 5 Previews:**
- Top Projects with progress bars
- Top Tags with progress bars
- Percentage breakdowns

#### 2. 📁 By Project Report
Detailed breakdown showing:
- Project name
- Number of entries
- Total time spent
- Average time per entry
- Percentage of total time
- Visual progress bars

Sorted by most time spent (descending)

#### 3. 🏷️ By Tag Report
Comprehensive tag analysis:
- Tag name (with badge styling)
- Number of entries using this tag
- Total time for this tag
- Percentage of total time
- Visual progress bars

Sorted by most time spent (descending)

#### 4. 📅 By Day Report
Daily time breakdown:
- Date
- Number of entries per day
- Total time per day
- Visual bar chart showing relative time
- Sorted by most recent first

### Filtering Options

#### Standard Filters
- **Project** - Filter by specific project or all projects
- **Tag** - Search for entries containing specific tags
- **Start Date** - Show entries from this date forward
- **End Date** - Show entries up to this date

#### Quick Date Filters
One-click date range selection:
- **Today** - Only today's entries
- **Yesterday** - Only yesterday's entries
- **Last 7 Days** - Past week
- **Last 30 Days** - Past month
- **All Time** - Remove date filters

#### Clear Filters
- **Clear All Filters** button removes all active filters

## 📈 Key Metrics Explained

### Total Time
Sum of all durations for filtered entries. Excludes:
- Active (non-stopped) timers
- Paused time (automatically subtracted)

### Days Tracked
Counts unique calendar dates where you logged time. Helps understand:
- Consistency of tracking
- Work patterns
- Average productivity per day

### Avg Per Day
Total time divided by days tracked. Shows:
- Daily work volume
- Work intensity
- Productivity trends

### Avg Per Entry
Average duration of individual time entries. Indicates:
- Task granularity
- Focus session length
- Work style patterns

### Percentage Breakdowns
Shows how time is distributed:
- Across projects
- Across tags
- By category

## 💡 Use Cases

### 1. Client Billing
**Goal:** Generate invoices for client projects

**Steps:**
1. Set date range (e.g., "Last 30 Days")
2. Filter by specific project
3. View "By Project" report
4. Export CSV for invoicing
5. See total hours and entries

### 2. Personal Productivity
**Goal:** Understand where time goes

**Steps:**
1. Use "All Time" filter
2. View "Overview" report
3. Check "Avg Per Day"
4. Review "Top Projects" and "Top Tags"
5. Identify time sinks or productive periods

### 3. Weekly Review
**Goal:** Review past week's work

**Steps:**
1. Select "Last 7 Days"
2. View "By Day" report
3. Check daily totals
4. See patterns and trends
5. Plan next week accordingly

### 4. Project Time Audit
**Goal:** Track time per project for resource allocation

**Steps:**
1. View "By Project" report
2. Sort by total time
3. Check percentage breakdowns
4. Identify over/under-resourced projects
5. Export data for stakeholders

### 5. Tag Analysis
**Goal:** Understand type of work being done

**Steps:**
1. View "By Tag" report
2. See distribution (e.g., "meetings" vs "coding")
3. Identify time balance
4. Make workflow adjustments
